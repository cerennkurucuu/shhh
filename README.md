# shhh.

WhatsApp ve diğer uygulamalardan paylaşılan veya elle seçilen sesleri cihazda yazıya dönüştürmeyi hedefleyen ücretsiz, local-first web uygulaması.

## Kullanım ve durum

Planlama aşamasında; henüz çalıştırılabilir uygulama yoktur. Hedef akış: ses paylaş/seç → yerel transkripsiyon → kopyala → başka ses ekle veya işlemi bitir ve temizle. Android PWA ve normal web; hesap, backend, ücretli AI API, reklam ve takip yoktur. Paylaşımın ağ güvenliği cihazda doğrulanmadan entegrasyon yayınlanmayacaktır.
